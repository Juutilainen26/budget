# 통합 가계부 (웹앱)

여러 은행·통장·증권·신용카드를 한곳에서 관리하는 모바일용 가계부입니다.
데이터는 **기기 브라우저에 저장**되고, 엑셀/JSON으로 백업·이동할 수 있어요.

## 파일 구성
- `index.html` — 앱 본체 (이 파일 하나로 동작)
- `manifest.webmanifest`, `sw.js`, `icon.svg` — 홈화면 설치·오프라인용

---

## 1. 바로 써보기 (PC에서 확인만)
`index.html` 을 더블클릭해서 브라우저로 열면 바로 동작합니다.
※ 단, 파일로 직접 열면 홈화면 설치·오프라인 기능은 제한돼요. 폰에서 앱처럼 쓰려면 아래 배포가 필요합니다.

## 2. 폰에서 앱처럼 쓰기 — GitHub Pages 배포 (권장)
1. GitHub에서 새 저장소(repository) 생성 (예: `budget`)
2. 이 폴더의 4개 파일을 저장소에 업로드 (드래그로 올려도 됨)
3. 저장소 → **Settings → Pages** 이동
4. Source를 **Deploy from a branch**, 브랜치 **main / (root)** 선택 후 Save
5. 1~2분 뒤 `https://<아이디>.github.io/budget/` 주소가 생김
6. 폰 브라우저(사파리/크롬)로 그 주소 접속 →
   - **아이폰**: 공유 버튼 → "홈 화면에 추가"
   - **안드로이드**: 메뉴(⋮) → "홈 화면에 추가" / "앱 설치"
7. 홈화면 아이콘으로 실행하면 전체화면 앱처럼 열립니다.

> 데이터는 그 주소(도메인)의 브라우저 저장소에 쌓입니다. 앱 삭제·브라우저 데이터 삭제 시 사라지니, 가끔 **설정 → 전체 백업(JSON)** 으로 저장해 두세요.

---

## 3. 기능
- **홈**: 총자산(순자산), 이번달 수입/지출, 카드 전월·이번달 사용액, 계좌별 잔액
- **거래 입력**(＋ 버튼): 지출 / 수입 / 이체 — 이체는 총자산이 변하지 않음
- **외화**: 금액은 원화로, `비고·외화 금액`에 외화 원금액 기록 (예: `$22`)
- **신용카드**: 카드로 지출하면 미결제 잔액이 쌓이고, 결제일에 `상환 입력` 버튼으로 은행→카드 이체 처리(전월 사용액 자동 입력)
- **할부**: 매월 청구분을 카드 지출로 기록하고 `할부` 칸에 메모
- **통계**: 이번달 카테고리 도넛 차트, 최근 6개월 수입·지출 막대 차트
- **예산**: 카테고리별 월 한도 설정, 사용률·잔여 표시
- **설정**: 계좌·카테고리 관리, 엑셀/JSON 백업·복원, 예시 지우기, 초기화

## 4. 백업 / 엑셀
- **엑셀 내보내기**: 설정 → 엑셀(xlsx)로 내보내기 (거래·계좌·카테고리 3시트)
- **엑셀 가져오기**: '거래' 시트를 같은 열 이름(날짜/구분/금액/카테고리/출금계좌/입금계좌/비고(외화)/할부/메모)으로 맞춰 가져오기
- **전체 백업(JSON)**: 모든 데이터를 파일로 저장 / 복원

## 5. 시작 전
설정 → 계좌 관리에서 각 계좌의 **초기 잔액**을 실제 값으로 넣어주세요.
확인용 `[예시]` 거래 4건은 설정 → **예시 거래 지우기**로 한 번에 삭제됩니다.

---
기본 계좌·카테고리는 일반적인 예시로 넣어뒀어요. 설정 → 계좌 관리에서 본인 계좌로 바꾸면 됩니다.
나중에 다기기 자동 동기화가 필요하면 GitHub 저장 방식으로 확장할 수 있습니다.
